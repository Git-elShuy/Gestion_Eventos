REGISTRAR ASISTENTE

La matricula es obligatoria. La matricula no debe contener letras.
La carrera es obligatoria.
El nombre es obligatorio.
El nombre solo debe contener letras.
El nombre debe tener al menos 3 caracteres.
El nombre no debe exceder los 20 caracteres.
El apellido es obligatorio. El apellido solo debe contener letras. El apellido debe tener al menos 3 caracteres. El nombre no debe exceder los 20 caracteres.
El celular es obligatorio. El celular debe contener maximo 10 dígitos y no debe incluir letras.
El correo electronico es obligatorio. Correo electronico invalido.
El permiso es obligatorio.
